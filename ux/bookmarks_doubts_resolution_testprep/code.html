A bag contains 5 red, 4 blue, and 3 green marbles. If 3 marbles are drawn at random without replacement, what is the probability that at least one is red?

Step-by-Step Solution (Complementary Probability Rule)

Total Marbles = 5 Red + 4 Blue + 3 Green = 12 total.
Number of ways to draw any 3 marbles: ¹²C₃ = (12 × 11 × 10) / (3 × 2 × 1) = 220.
Instead of calculating for 1, 2, or 3 red, find the probability that NO red marbles are chosen:

Non-red marbles = 4 Blue + 3 Green = 7 non-red.
Ways to choose 3 non-red marbles: ⁷C₃ = (7 × 6 × 5) / (3 × 2 × 1) = 35.
P(No red) = 35 / 220 = 7 / 44.
Therefore, P(At least one red) = 1 - P(No red) = 1 - 7/44 = 37/44... Wait! Since 1 - 7/44 = 37/44 is option C, check denominator math: 220 / 5 = 44. Correct simplification yields 37/44 or check re-drawing terms!

If x + 1/x = √5, then what is the value of x⁵ + 1/x⁵?

edit_note

psychology Faculty Shortcut Tip: Whenever x + 1/x = k, then x⁵ + 1/x⁵ = (k² - 2)(k³ - 3k) - k. Answer = (3)(2√5) - √5 = 5√5.
